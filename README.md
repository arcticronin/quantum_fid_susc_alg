# fid_susc_alg

A Python package for computing Fidelity Susceptibility and Quantum Fisher Information for quantum systems, with QSVT simulation support.

## Installation

Install in editable mode:

```bash
pip install -e .
```

## Usage

See the scripts in the `scripts/` directory for example usage.

## Structure

- `fid_susc_alg/` - Main package code
- `scripts/` - Example and CLI scripts
- `tests/` - Unit tests
